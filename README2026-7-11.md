# Replication Materials for "Playing with Time: Data Manipulation within the Performance Evaluation Cycle"

This repository contains the data, code, figures, and supplementary quarterly environmental-control data for:

> Li, Jiayuan, Zhibin Chen, Manqian Cui, and Xuelian Zhang. 2026. "Playing with Time: Data Manipulation within the Performance Evaluation Cycle." *Journal of Public Administration Research and Theory*. https://doi.org/10.1093/jopart/muag017

## Repository contents

| File | Software / format | Description |
|---|---|---|
| `Master.do` | Stata | Main replication script for the descriptive statistics, regression models, robustness checks, moderation analyses, and Stata-generated figures. |
| `main.dta` | Stata | Main city-quarter analysis dataset used by `Master.do`. It already contains the four environmental controls used in the published models. |
| `figure1_adjusted_quarterly_gdp.R` | R | Produces Figure 1 using `adjusted_quarterly_gdp.xlsx`. Requires the R packages `tidyverse` and `readxl`. |
| `adjusted_quarterly_gdp.xlsx` | Excel / R input | Predicted quarterly GDP values used by the Figure 1 R script. |
| `figure 4_Adjusted_Effect_of_Quarter_on_GDP_Manipulation.R` | R | Produces Figure 4 from the reported regression coefficients. Requires `tidyverse`; the script also loads `haven`. |
| `Figures in the manuscript2026-6-24.zip` | ZIP archive of JPG images | Contains the four final manuscript image files: `Figure_1.jpg`, `Figure_2.jpg`, `Figure_3.jpg`, and `Figure_4.jpg`. No statistical software is required to view them after extraction. |
| `seasonal_environmental_controls_release.zip` | ZIP archive of data, documentation, and Python code | Supplementary package containing the source data, cleaning workflow, validation report, and analysis-ready quarterly AQI, temperature, precipitation, and sunshine-duration data. |

## 1. Main statistical analysis in Stata

Requirements:

- Stata. The code uses commands including `mixed`, `xtreg`, and `xtabond`.
- User-written Stata commands used in parts of the script may need to be installed, including `esttab`/`eststo`, `r2_nakagawa`, and `xtserial`.

Steps:

1. Download `Master.do` and `main.dta` to the same folder.
2. Open `Master.do` in Stata.
3. Replace `Set your path here` in the `cd` command with the local folder containing the downloaded files.
4. Run `Master.do`.

The main dataset includes the following quarterly environmental variables:

- `aqi`: Air Quality Index.
- `Temperature`: average temperature.
- `Precipitation`: mean daily precipitation measure used in the paper.
- `Sunshine`: sunshine duration.

## 2. Figures generated in R

### Figure 1

Keep the following files in the same working directory:

- `figure1_adjusted_quarterly_gdp.R`
- `adjusted_quarterly_gdp.xlsx`

Install the required packages and run the script:

```r
install.packages(c("tidyverse", "readxl"))
source("figure1_adjusted_quarterly_gdp.R")
```

The script creates `Adjusted_GDP_Trends_with_Shading.png`.

### Figure 4

Install the packages and run:

```r
install.packages(c("tidyverse", "haven"))
source("figure 4_Adjusted_Effect_of_Quarter_on_GDP_Manipulation.R")
```

The script creates `figure 4.png`. Its coefficient and standard-error inputs are recorded directly in the R script.

## 3. Final manuscript images

`Figures in the manuscript2026-6-24.zip` is an image archive, not a data or code archive. After extraction, it contains the final JPG versions of Figures 1-4 used in the manuscript.

## 4. Quarterly environmental-control data

Download and extract `seasonal_environmental_controls_release.zip`. The archive contains:

- `raw/`: source files used to construct the quarterly controls.
- `scripts/01_build_quarterly_controls.py`: reproducible Python cleaning script.
- `processed/`: cleaned quarterly files in both CSV and Stata formats.
- `DATA_DICTIONARY.md`: English variable definitions.
- `SOURCE_NOTES.md`: source information, transformations, and limitations.
- `validation/validation_report.json`: comparison with the environmental variables in `main.dta`.
- `RELEASE_CHECKLIST.md`: redistribution and release notes for the source files.

The recommended ready-to-use files are:

- `processed/environmental_controls_quarterly_2013_2020.dta` for Stata.
- `processed/environmental_controls_quarterly_2013_2020.csv` for R, Python, Stata, or other statistical software.

The combined environmental dataset retains all available observations from 2013 Q1 through 2020 Q4. The published main analysis sample runs from 2013 Q1 through 2020 Q1.

### Rebuilding the quarterly controls

The seasonal-data cleaning workflow uses Python, not R.

```bash
python -m pip install -r requirements.txt
python scripts/01_build_quarterly_controls.py
```

To verify the reconstructed controls against the repository's `main.dta`, place the extracted seasonal package beside `main.dta` and run:

```bash
python scripts/01_build_quarterly_controls.py --reference-main ../main.dta
```

The raw precipitation file is stored as a losslessly compressed `.csv.gz` file. The Python script reads it directly; manual decompression is not required.

## Data and code notes

- Missing environmental observations are retained as missing; the seasonal-data workflow does not interpolate or impute values.
- The reconstructed AQI, temperature, precipitation, and sunshine-duration controls match the corresponding nonmissing values in `main.dta` within the documented source-precision tolerances.
- The source-data folders do not contain complete redistribution-license documentation for every third-party provider. Users and repository maintainers should consult `RELEASE_CHECKLIST.md` in the seasonal package.
- The author-written replication code and third-party source data may be subject to different licensing conditions.
